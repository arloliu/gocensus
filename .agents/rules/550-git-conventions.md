# 550 - Git Conventions

Apply when creating branches, commits, PR titles, or PR descriptions.

## Commit Messages

- Use Conventional Commits: `feat`, `fix`, `docs`, `test`, `refactor`, `chore`, `perf`.
- Keep the subject present-tense and concise.
- Add a body only when the why is not obvious from the subject and diff.
- Never add `Co-Authored-By` or any other attribution trailers.

## Branches

Use simple prefixes when creating branches:

```text
feat/
fix/
docs/
test/
refactor/
chore/
```
